### 🚀 **Featured Projects**

#### **1. 💹 [Real-Time Stock Market Data Pipeline](https://github.com/EAZY-647/real_time_stock_analysis_with_data_engineering)**
*An industry-level End-to-End streaming architecture.*

> **Tech:** Kafka, Airflow, Snowflake, dbt, Docker, MinIO, Power BI.

* **Streaming Ingestion:** Deployed Kafka producers/consumers in Docker to ingest live financial data.
* **Lakehouse Architecture:** Simulated S3 storage with MinIO and loaded data into Snowflake.
* **Transformation:** Implemented Bronze/Silver/Gold layers using **dbt** for rigorous data modeling.

#### **2. 🚁 [Databricks x dbt: Production-Grade Lakehouse](https://github.com/EAZY-647/Databricks_end_to_end_flights)**
*A scalable ETL pipeline implementing the Medallion Architecture.*

> **Tech:** Databricks, Spark Structured Streaming, Auto Loader, Unity Catalog.

* **Dynamic Schema Evolution:** Used **Auto Loader** to handle incremental file ingestion and schema drift.
* **Custom SCD Framework:** Built a **Dynamic Star Schema Builder** to handle Slowly Changing Dimensions (SCD Type 1 & 2) automatically.
